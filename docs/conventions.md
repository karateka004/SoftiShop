# conventions.md — соглашения

## Язык
- **Текст сайта — украинский** (как в IG бренда). Alt/ARIA — тоже украинский.
- Комментарии/документация в коде — русский (язык владельца), допустим украинский в копирайтинге.

## Именование
- Файлы компонентов: `kebab-case.tsx` (напр. `product-card.tsx`).
- React-компоненты: `PascalCase`. Хуки: `useCamelCase`. Типы/интерфейсы: `PascalCase`.
- Роуты — папки в `app/` (App Router). Динамика — `[handle]`.

## Компоненты
- **Не дублировать разметку** — выносить в переиспользуемые компоненты (`components/`).
- Базовые примитивы — из `components/ui` (shadcn). Не плодить «сырые» `<button>/<input>`,
  если есть shadcn-аналог.
- Server Components по умолчанию; `"use client"` — только где нужна интерактивность
  (корзина, выбор размера, мобильное меню).
- Данные тянуть через `lib/commerce.ts` (await в Server Component).

## Стили и токены
- **Только токены `@theme`**: `bg-bone`, `text-ink`, `text-ink-soft`, `border-line`,
  `bg-pink`, `text-on-pink` и т.п. **Без хардкода hex/px** в разметке.
- Шрифты — через классы `font-display` / `font-head` / `font-sans` (Фаза 1).
- Mobile-first: базовые стили — мобильные, далее `sm: md: lg:`.
- Радиусы/отступы — из шкалы; острые углы по умолчанию, pills только для бейджей.

## Доступность (a11y)
- Каждое изображение — осмысленный `alt` (украинский). Декор — `alt=""`.
- Видимый фокус (`focus-visible` ring через токен), порядок табуляции, семантика
  (`<header> <nav> <main> <footer>`, заголовки по иерархии).
- Контраст ≥ AA. На розовом — тёмный текст (`--color-on-pink`).
- Интерактив доступен с клавиатуры; модалки/дроверы — с ловушкой фокуса (shadcn даёт).

## Картинки
- `next/image` с явными размерами/`sizes`. Фото товаров — из `public/products/<handle>/`.
