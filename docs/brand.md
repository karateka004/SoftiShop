# brand.md — айдентика Softi

## Бренд
- **Название:** Softi · **Instagram:** [@softi.brand](https://instagram.com/softi.brand)
- **Что продаём:** кастомные **oversize-футболки**, washed / vintage black, арт-принты
  (butterfly, контрастные). «Кожна річ унікальна» — мелкие дропы, 1-of-1.
- **Аудитория:** молодёжь ~16–25, украинский streetwear, ценят «дорогой effortless» вид
  без логомании.
- **Вайб:** тёмный минималистичный streetwear; «soft» имя × «metal» подача — мягкое имя,
  дерзкая готическая графика, washed-чёрный.
- **Тон голоса:** тёплый, лаконичный, с эмодзи, **на украинском**.
  Образцы из IG: «Кожна річ унікальна 🔥», «Доставка 1–2 дні», «Замовлення через direct ❤️».
- **CTA вместо оплаты:** «Замовити в Direct» → `https://instagram.com/softi.brand`.

## Дизайн-токены (ПРЕДЛОЖЕНИЕ — применяем в Фазе 1 после «ОК»)

### Палитра — «washed bone gallery»: монохром + розовый акцент
Основной режим — **светлый** (галерейный, как byedemox; чёрные товары «звучат» на кремовом).
Тёмный — лёгкий alt-переключатель (токены те же).

| Токен | HEX | Назначение |
|---|---|---|
| `--color-bone` | `#F4F1EB` | фон страницы (тёплый washed off-white) |
| `--color-paper` | `#FFFFFF` | карточки / товарные ячейки |
| `--color-ink` | `#121211` | основной текст, «washed black» |
| `--color-ink-soft` | `#6B6760` | вторичный текст |
| `--color-line` | `#E4DFD5` | hairline-границы |
| `--color-line-strong` | `#121211` | brutalist-обводка (= ink) |
| `--color-pink` | `#FF2E7E` | акцент: CTA, бейджи, ховеры |
| `--color-pink-soft` | `#FF7AB0` | tint/hover розового |
| `--color-on-pink` | `#121211` | текст/иконки на розовом (постерный контраст) |

Dark alt: bone→`#0D0D0C`, paper→`#161614`, ink→`#F4F1EB`, line→`rgba(244,241,235,.12)`, pink — тот же.

### Типографика (Google Fonts, через `next/font`)
- `--font-display` — **Metal Mania** *(Latin only)*: ТОЛЬКО логотип «SOFTI» и редкие крупные
  латинские акценты. Никогда для абзацев и украинского текста. Alt: **Pirata One**.
- `--font-head` — **Oswald** *(Cyrillic ✓)*: заголовки, навигация, названия товаров. Condensed,
  перекликается с жирным гротеском логотипа.
- `--font-sans` — **Inter** *(Cyrillic ✓)*: body/UI, кнопки, цены, описания.

Шкала (fluid, `clamp`): `display` (только акценты) → `h1` → `h2` → `h3` → `body` → `small`;
`eyebrow` = UPPERCASE + увеличенный трекинг (на Oswald/Inter).

> ⚠️ Украинский = обязательная поддержка кириллицы. Metal Mania/Pirata One кириллицу НЕ
> поддерживают → их домен только латиница (логотип/акценты). Заголовки/текст — Oswald/Inter.

### Форма
- `--radius: 0` — острые углы (галерейно/brutalist). Исключение: **pill-бейджи** (`9999px`)
  для «новинка» / «продано» (как у byedemox).
- Отступы: базовая шкала Tailwind (4px). Ритм секций: `clamp(4rem, 10vw, 8rem)` по вертикали.
- Границы: hairline 1px (`--color-line`); сильная обводка товарных ячеек — `--color-ink`.

### Движение
Сдержанно: 150–250ms, ease-out. Ховер карточки — лёгкий зум фото (~1.03). Ссылки — reveal
подчёркивания. Без тяжёлых градиентов/глассморфизма.
